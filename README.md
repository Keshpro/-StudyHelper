## ⚡ About StudyFlow

StudyFlow is a modern exam preparation web application that
combines academic productivity, gamification, and mental
wellness into one seamless digital experience.

Designed to replace boring study routines with an interactive
and personalized learning environment.

## 🚀 Getting Started

### Step 01 — Download

Download or clone this repository.

### Step 02 — Launch

Open `studyflow.html` in your preferred web browser.

### Step 03 — Personalize

Add your subjects, lecture topics, examination dates,
and daily study goals.

### Step 04 — Start Learning

Track your progress, complete focus sessions,
and build consistent learning habits.
